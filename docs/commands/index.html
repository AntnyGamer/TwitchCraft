Before you use a command

1.

Replace placeholders

Copied syntax is a template. Replace values in <angle brackets>; square brackets indicate optional arguments.

2.

Costs are defaults

The price multiplier above is a preview, not a live connection to a streamer's settings. It affects gameplay command prices only. Multiplayer targeting scales the base cost by (player count + 1) / 2 (rounded down), then applies the multiplier (rounded up).

3.

Some commands are conditional

Chicken Run, Number Guess, and Wither Battle commands require an active round; !gambletokens works independently. Some admin commands require local multiplayer.

Token rewards: If Bit rewards are enabled, 1 Bit earns 1 token. New followers receive a one-time reward of 50 tokens by default, unless the streamer changes the amount. Streamer commands are for the broadcaster and bot, and moderators where enabled.
