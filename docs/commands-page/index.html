Singleplayer and multiplayer targeting

In singleplayer, gameplay commands affect the streamer's Minecraft player. In multiplayer or Remote Control Mode, most gameplay commands let you choose who to target:

No player specified

!heal

Targets the streamer's configured Minecraft player. If they are offline and only one other player is online, that player is used. Otherwise, specify a player name.

Specific player

!heal Steve

Targets that online Minecraft player only. Use their Minecraft username, not their Twitch username.

Everyone

!heal all

Targets all eligible online players. The token cost increases with the number of players targeted. The streamer can disable this option.

Random player

!heal random

Selects one random online player. The streamer can disable this option; unavailable targets can be rejected.

Arguments: Some commands put other values before the target, for example !effect 3 all or !addheart 2 Steve. Follow the syntax shown on each command card. World, minigame, and token commands do not necessarily accept player targets.

Multiplayer costs: One player pays the listed base price. For multiple players, the base cost is multiplied by (player count + 1) ÷ 2 and rounded down, then the configured cost multiplier is applied and rounded up. Spectators and other ineligible targets may be excluded. Multiplayer setup guide ↗

Before you use a command

1.

Replace placeholders

Copied syntax is a template. Replace values in <angle brackets>; square brackets indicate optional arguments.

2.

Costs are defaults

The price multiplier above is a preview, not a live connection to a streamer's settings. It affects gameplay command prices only; actual prices can differ.

3.

Some commands are conditional

Chicken Run, Number Guess, and Wither Battle commands require an active round; !gambletokens works independently. Some admin commands require local multiplayer.

Token rewards: If Bit rewards are enabled, 1 Bit earns 1 token. New followers receive a one-time reward of 50 tokens by default, unless the streamer changes the amount. Streamer commands are for the broadcaster and bot, and moderators if enabled.

!gambletokens Command Help — risk levels, odds and payouts

Command: !gambletokens <amount> [risk 1-10] (example: !gambletokens 20 5).

Enter the number of tokens you want to gamble (minimum 5, maximum 150). Choose a risk level from 1–10. Higher risks have a lower chance of winning but a higher payout. The risk argument is optional and defaults to 5.

Multipliers and win chances are rounded for display. Actual token gains are rounded to whole tokens, with at least one token gained on a win.

Example: A winning 150-token gamble at risk 10 gains 300 tokens, equivalent to 450 tokens returned including the 150-token stake. A loss deducts the tokens gambled. A configured maximum token balance may cap the amount gained.

Cooldown: Five minutes per viewer by default; custom command cooldown settings can override it.
