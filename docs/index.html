BEFORE YOU SEND

Know the rules

01

Replace placeholders

Copied syntax is a template. Replace values in <angle brackets>; square brackets indicate optional arguments.

02

Costs are defaults

Streamers can change prefixes, token multipliers, permissions, enabled commands, and cooldowns. Multiplayer targeting can raise token costs.

03

Some commands are conditional

Minigame commands work only during their rounds. Certain admin commands require broadcaster or moderator permission and local multiplayer.
